Featured ML Research

XGBoost · Tabular ML · Statistical Inference Statistical Feature Significance for XGBoost

Extended target-permutation inference to XGBoost using Total Gain to generate empirical feature-level p-values while preserving predictor dependence. Evaluated across 12 real-world classification and regression datasets, including datasets approaching 1M observations.

Significance-based pruning reduced the Higgs feature set from 24 to 11 (>55%) without loss of predictive integrity and achieved up to 86% dimensionality reduction in regression while maintaining strong predictive performance.

Neural Networks · Feature Significance · XAI Target Permutation Testing for Differentiable Models

Developed a target-permutation framework that produces empirical p-values for neural-network features without requiring predictor independence, supporting nonlinear signal detection, multicollinearity resilience, and statistically grounded feature selection.

Feature reduction maintained or improved predictive performance while removing up to 50% of features on credit-default data and more than 60% on road-safety data. View implementation →
